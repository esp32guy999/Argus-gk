## Observability (caught a cargo-cult)
Prometheus was a "cornerstone" that wasn't functioning: metrics were emitted natively
(registry/loop/watchdog) but **never exposed in the running server** (`serve()` only ran
in the CLI path) and **had no consumer** — present, not working. Fixed: mounted
`/metrics` on the live server (`:8210/metrics`), instrumented the Claude Code path
(`CC_TURNS`/`CC_COST`/`CC_DURATION`), and added **`argus/observability.py`** — an
in-process SelfObserver that reads its own registry and **buzzes via HA** on agent error
spikes / watchdog loops / no-progress / CC error bursts / CC cost steps (per-rule
cooldown). Contract tests (`test_metrics.py`, `test_observability.py`) **prove it fires**,
so it can't rot back into theater. uptime-kuma still covers is-it-up; the observer covers
is-it-degrading. (No external Prometheus needed; one can still scrape `/metrics` for trends.)
LESSON: a cornerstone needs a test that proves it *functions end-to-end*, not just code that *looks* present.
