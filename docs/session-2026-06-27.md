  TIGHT found 0 (correct silence), 11× faster. Use loose (high recall) for a first audit of new
  code, tight (high precision, demands a repro `trigger`) for steady state.

  evaluation — under-fires). Recorded in the model docs. NB: don't trust the 80b's confidence
